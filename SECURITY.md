# Security policy

This repository is a public synthetic portfolio demonstration. Do not submit
real credentials, personal information, employer/client records, municipal
asset data or infrastructure-sensitive details in an issue or pull request.

For the implemented trust boundaries, abuse cases and residual risks, read
[`docs/security/THREAT_MODEL.md`](docs/security/THREAT_MODEL.md). If you believe
the public code or hosted demonstration exposes sensitive information, contact
the repository owner privately through the profile contact method and include
the affected URL/commit, impact and reproduction steps without including the
sensitive value itself.

Supported security fixes are applied to the current default branch. This
portfolio repository does not publish a long-term-support version matrix.
